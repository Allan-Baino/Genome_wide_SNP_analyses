
**The aim of this project/analysis layout is to detail the prcoess of generating a high confidence dataset of variants for African giant pouched rats individuals sequenced by the ddRAD technique**

**Brief overview**
Raw paired-end reads ~ 150 bp, were generated on an illumina NovaSeq X series system. Knowledge of ddRADseq (Peterson et al., 2012), BASH and access to a high performance computing cluster preferably SLURM is recommended.
Knowledge of dual-indexed sample demultiplexing is recommended and is NOT covered in appended scripts.  

**Scripts' description** 
Uploaded scripts provide an analysis workflow for short-read sequence data generated by the ddRAD method;
