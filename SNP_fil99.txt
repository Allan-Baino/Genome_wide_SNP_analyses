# SNP filtering - here we want to remove loci that do not meet our filtering criteria, best to 
# apply filters one at a time and keep track of loci retained, and understand stringency/leniency

# f1 - Biallelic loci - filter the .vcf to remain with loci that have 2 alleles (min 2 and max 2)

# variant sites dropped to 622,310.

# f2 - Missing data - here we want to set a threshold on how many individuals of 108 should miss a GT call,
# best to be stringent when sample size is small (relative to similar research or can be arbitrary), opted
# for 99% allowed samples with missing GT calls, which means approx. 1% of 108 indvs will not have a missing GT.

# variant sites dropped to 31,546.

# f3 - MAF/MAC - removing less frequent alleles at variant sites i.e. remove loci where the
# the minor allele occurs rarely in a sample and doesn't provide much info compared to other

# f5 - Hardy-Weinberg Equilibrium - it might make sense to test for HWE and exclude variant sites that 
# significantly depart from expected HWE. In the absence of evolutionary influences, allele frequencies
# in a population remain constant from generation to generation. A p-value of 0.05 will test whether 
# each biallelic SNP deviates significantly from expected HWE and remove them (p < 0.05), leaving only 
# SNPs that conform.  
vcftools --vcf cans_108inds_minDP10GQ20_biallelic_0.99missing_maf5%_maxDP.recode.vcf --hwe 0.05 --recode --out cans_108inds_minDP10GQ20_biallelic_0.99missing_maf5%_maxDP_hwe

# variants sites dropped to 9,508.

# f5 - Linkage Disequilibrium - Estimating how much LD exists for variants in your dataset could be an important aspect
# to look out for. SNPs that are physically close to each other on a chr are more likely to be inherited together.
# SNPs in high LD are likely to be less independent and may lead to redundancies in downstream analyses. Always best to
# focus more on independent markers. You can do this by generating a report on LD for SNPs in the dataset using the 
# --hap-r2 flag, use report to establish an r2 range for pairs of variants at specific bp distances to get a reasonable 
# --thin <value>. You can also calculate LD between pairs of variants within a certain bp distance and remove one of each 
# pair that appears to be in high LD (Plink v1.9 is best for this)...which is what I went for.    

# before using the --hap-r2 flag, use shapeit to convert data in .vcf to phased genotypes to enable vcftools to calculate
# LD from haplotypes which is a bit involved...more on Shapeit4 see, https://odelaneau.github.io/shapeit4/ 
shapeit4 --input data.vcf ---output data_phased.vcf

# using Plink, which needs data to be specifically formatted, e.g. ref genome should be similar to how the human genome
# appears. So we shall manually edit our .vcf to have contig_poistion as the third argument in the .vcf and use the 
# --allow-extra-chr flag to make Plink accept numerous contigs within the pouched rat genome 

# format .vcf file
# run Plink (--indep-pairwise command) on annotated .vcf to output .prune.in (loci in approx. LD with each other) and 
# .prune.out (loci for exclusion) files command below follows an examining window size (50kb), step size (10 SNPs) and 
# r2 threshold (0.5)  
plink --vcf cans_108inds_minDP10GQ20_biallelic_0.99missing_maf5%_maxDP_hwe.annotated.vcf --indep-pairwise 50 5 0.5 --allow-extra-chr --out cans_108inds_minDP10GQ20_biallelic_0.99missing_maf5%_maxDP_hwe    

# let's modify .prune.in file to output a .txt with loci we want to keep in our dataset
awk 'BEGIN {OFS="\t"} {gsub(/_/,"\t", $0); $2=$2}1' cans_108inds_minDP10GQ20_biallelic_0.99missing_maf5%_maxDP_hwe.prune.in > good_LD_sites.txt

# create function to convert genotypes (0/0, 0/1, 1/1, ./.)
con_gen <- function(genotype) {
  if (genotype == "0/0") return(0)  # homozygous reference
  if (genotype == "0/1") return(1)  # heterozygous
  if (genotype == "1/1") return(2)  # homozygous alternate
  return(NA)  # missing data (./.)
}
